# Motores de Plantilla

Este proyecto está organizado por carpetas para mostrar el uso de distintos frameworks y motores de plantillas en diferentes tecnologías:

- **Express** usando los motores de plantilla **EJS** y **Pug**.
- **Spring** con el motor de plantillas de **Spring Boot**.
- **Django** usando **Django Templates**.

La idea del repositorio es comparar y practicar cómo se renderizan vistas dinámicas en cada entorno.
