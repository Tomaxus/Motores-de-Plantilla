# 🚀 Motores de Plantilla

Repositorio académico que reúne ejemplos prácticos de motores de plantilla implementados en diferentes frameworks para el desarrollo de aplicaciones web.

## 📖 Descripción

Este proyecto tiene como objetivo comparar la implementación y el funcionamiento de distintos motores de plantilla utilizados en aplicaciones web modernas.

Se incluyen ejemplos desarrollados con:

- Django
- Express.js
- Spring Boot

Cada proyecto demuestra cómo generar vistas dinámicas utilizando el motor de plantilla correspondiente.

---

## 📂 Estructura del repositorio

```
Motores-de-Plantilla/
│

│
├── EXPRESS/

│
└── SPRING BOOT/
```

## 🎯 Objetivos

- Comprender el funcionamiento de los motores de plantilla.
- Comparar diferentes frameworks para el desarrollo web.
- Aplicar la arquitectura MVC.
- Desarrollar aplicaciones web dinámicas utilizando tecnologías actuales.

## ▶️ Ejecución de los proyectos

### Django

```bash
cd DJANGO
python -m venv .venv

# Windows
.venv\Scripts\activate

pip install -r requirements.txt

python manage.py runserver
```

---

### Express

```bash
cd EXPRESS
npm install
npm start
```

---

### Spring Boot

```bash
cd "SPRING BOOT"
./mvnw spring-boot:run
```

También puede ejecutarse desde IntelliJ IDEA, Eclipse o Visual Studio Code.
